# FFmpeg Addon

This directory contains the FFmpeg addon used by XRCinemon.

## Sources

- **Godot addon:** https://github.com/EIRTeam/EIRTeam.FFmpeg
- **Addon release:** [v1.1.4](https://github.com/EIRTeam/EIRTeam.FFmpeg/releases/tag/autobuild-2025-11-12-13-44)
- **FFmpeg Kit:** https://github.com/arthenica/ffmpeg-kit/tree/e78b7956c7efd76e61930d9b3571773804c30565
- **FFmpeg Kit revision:** `e78b7956c7efd76e61930d9b3571773804c30565`

The addon binaries were obtained from the EIRTeam.FFmpeg release linked above.

The exact FFmpeg version used in these binaries has not yet been identified.
